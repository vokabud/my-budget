# Repository Agent Instructions

## Specifications and implementation plans

When creating or updating specifications and implementation plans:

- Do not include steps or instructions for `git add`, `git commit`, creating commits, commit messages, commit hashes, staging gates, or commit-based prerequisites.
- Explicitly state that the implementing model must leave all changes uncommitted for the user to review and commit manually.
- Do not create commits unless the user explicitly requests a commit in the current conversation.
